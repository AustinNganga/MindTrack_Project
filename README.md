# MindTrack Project — Depression (Beck score) prediction for a mobile app

## How to run

Open `notebooks/Pipeline.ipynb` and choose **Kernel → Restart & Run All** (about 3–6 minutes). The whole workflow runs inside the notebook: cleaning, EDA, split, feature-group comparison, PCA, model comparison, compact question set, threshold, test evaluation, regression and mobile export. No external scripts are called.

```bash
source ~/.venvs/mindtrack/bin/activate        # or any Python 3.10+ environment
pip install pandas numpy scikit-learn matplotlib seaborn openpyxl joblib jupyter
```

## Headline result

| | CV (training, 5×3 folds) | Held-out test |
|---|---|---|
| Final random forest, 15 app inputs: ROC-AUC | ≈ 0.75 | ≈ 0.77 |
| PR-AUC (no-skill = 0.18) | ≈ 0.42 | ≈ 0.39 |
| Sensitivity at screening threshold | ≈ 0.75 (by design) | 0.75 |
| Previous feature set (background + TMD total): ROC-AUC | ≈ 0.64 | ≈ 0.65 |

**Why it improved:** the background and phone-use fields carry very little signal (every |ρ| < 0.2). The anxiety questionnaire (STAI) carries much more, but the old pipeline excluded it. Its supplied totals were also never reverse-scored, so the opposite-direction items cancelled out and the totals looked useless. Using the STAI item answers with a random forest fixes this. PCA was tested inside cross-validation and *reduced* performance, so the final model does not use it.

## Android integration (on-device, offline)

1. Copy `app/mindtrack_model.json` to `app/src/main/assets/` and `MindTrackModel.kt` into your source package.
2. Build a form for the 15 fields in `app/app_input_fields.csv`. `TMD_Total` is the sum of the 22 TMD answers (0–4 each), so the form asks all 22 and sums them.
3. `MindTrackModel.fromJson(...).predict(map)` returns a probability and a level, `Low` or `Elevated`.
4. Always show the disclaimer: *screening estimate, not a diagnosis*. Also include a link to campus counselling services.

## Limitations

Cross-sectional data from one institution. The Beck form version should be confirmed against its scoring guide. Some STAI items appear to have been misread by respondents. The department, age and row-order patterns suggest collection-batch effects. The test set has only 44 positive cases. The model shows association, not causation. It is **not a diagnostic tool**.
